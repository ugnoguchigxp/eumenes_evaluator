入力の skillMarkdown は、呼び出し元が選んだ今回のレビュー基準です。focus と合わせて、調べる対象、候補の採用・除外、優先順位を決めてください。確定条件の照合も行ってください。Markdown の基準に入らない候補は、確定条件の違反に該当する場合に報告します。観点内で根拠のある候補がなければ、指摘は空で構いません。

通常の指摘には、差分が何を変えたか、成立条件から影響までどの経路をたどるかを示してください。候補を返す前に、引用箇所だけでその経路を読み直してください。変更箇所は primary、因果の途中や利用上の結果を示す行は evidence に引用してください。

Markdown は評価方法として扱います。評価範囲、固定資料、確定条件、出力形式、根拠の要件、権限には Evaluator の契約を適用してください。Markdown の参照先は、本文に含まれる内容を使ってください。指摘の根拠は入力の evidence から引用してください。
